# 普通话日常操作视频

[观看或下载视频](YouTubeToUSB-Mandarin-Guide.mp4)

约 37 秒，仅演示解压完成后每次下载歌曲的操作，不展示转换进度、NEXT SONG 或 DONE。

1. 双击打开程序：插好优盘，双击桌面上的下载程序。
2. 打开浏览器，进入 YouTube：打开浏览器，进入油管网站。
3. 输入歌曲名称，点击搜索：输入歌名，例如茉莉花，点击搜索。
4. 打开想下载的歌曲：打开你想下载的歌曲。
5. 复制浏览器上方的网址：复制浏览器上方的完整网址。
6. 切换回程序，粘贴链接：切换回下载工具，点击空白框，粘贴网址。
7. 点击 START，开始下载：点击蓝色的开始按钮，开始下载。请先不要拔出优盘。

画面为模拟 Windows 桌面和 YouTube 页面，歌曲与网址仅供示意。程序画面来自项目界面；没有实际下载音乐或操作真实 USB。

普通话为合成配音，使用 [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) 与官方发布的 [VITS AISHELL-3 模型](https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/vits-zh-aishell3.tar.bz2)。视频不包含模型文件或第三方音乐。
